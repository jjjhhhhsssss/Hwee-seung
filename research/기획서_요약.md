### 그래서 (우리 해석)

- 테마 때문에 광주에 오는 사람은 많아지고 있음 (야구, 음식, 팬덤)
- 야구장은 외지인이 가장 많이 찾고, 다른 곳으로 이어지는 출발점임
- 하지만 "야구장 다음엔 어디 가지?"를 알려주는 정보가 없음
- → **테마 하나만 고르면 장소와 동선을 한 번에 보여주는 서비스**가 필요함

## 2. 기획 서비스

### 서비스 한 줄 소개

광주에 처음 오는 외지인이 **관심 테마 하나를 고르면**, 갈 곳과 이동 순서를 한 번에 추천해주는 서비스

### 목적

- 테마만 고르면 갈 곳과 이동 순서를 한 번에 받기
- 장소마다 위치, 운영시간, 금액, 주차, 화장실을 **같은 기준으로 비교**하기
- 트랙(푸드 & 리테일)에 맞춰 가게·스토어처럼 **실제로 뭘 사고 먹는 장소** 중심으로 구성하기

### 테마 (예시)

| 테마 | 추천 장소 예시 |
|---|---|
| 야구팬 | 챔피언스필드, 타이거즈 굿즈 스토어, 사장님이 타이거즈 팬인 가게 |
| 아이돌팬 | 제이홉 관련 장소 (공식적으로 알려진 곳만) |
| 빵지순례 | 광주 대표 빵집 |
| 그 밖에 | 역사(5·18), 골목 산책(양림동), 시장 먹거리(1913송정역시장) |

### 보여줄 정보

| 항목 | 기준 |
|---|---|
| 위치 | 주소 |
| 운영시간·휴무일 | 24시간제 (예: 09:00–21:00) |
| 금액 | 대표 품목 가격, 원 단위 |
| 주차 | 무료 / 유료 / 불가 |
| 화장실 | 가게 안 / 건물 공용 / 없음 |
| 출처·기준일 | 언제, 어디서 확인한 정보인지 |

- 확인 안 된 정보는 짐작하지 않고 **"미확인"** 으로 표시

### 사용 흐름

1. 테마 고르기 (예: 야구팬)
2. 추천 장소 목록 보기 (예: 야구장 → 굿즈샵 → 주변 맛집)
3. 장소별로 운영시간·가격·주차·화장실 비교하기
4. 반나절 또는 하루 동선 받기
